# R Programming Training Environment

Welcome to your R learning workspace!

## Prerequisites - Installing R

### Step 1: Install R
1. Visit: https://cran.r-project.org/
2. Click "Download R for Windows"
3. Click "base" or "install R for the first time"
4. Download and run the installer (R-4.x.x-win.exe)
5. Follow the installation wizard (default settings are fine)

### Step 2: Install RStudio (Recommended IDE)
1. Visit: https://posit.co/download/rstudio-desktop/
2. Download RStudio Desktop (free version)
3. Install after R is installed

### Step 3: Verify Installation
Open PowerShell or Command Prompt and run:
```
R --version
```

## Learning Path

Follow these files in order:

1. **01_hello_world.R** - Your first R script
2. **02_basics.R** - Variables, data types, and basic operations
3. **03_data_structures.R** - Vectors, lists, matrices, and data frames
4. **04_control_flow.R** - If statements, loops, and functions
5. **05_data_manipulation.R** - Working with data
6. **06_plotting.R** - Data visualization
7. **07_statistics.R** - Basic statistical operations
8. **exercises.R** - Practice problems

## Running R Scripts

### In Terminal/PowerShell:
```powershell
Rscript 01_hello_world.R
```

### In R Console:
```r
source("01_hello_world.R")
```

### In RStudio:
- Open the file and click "Run" or press Ctrl+Enter
